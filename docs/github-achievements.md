# Earning Pull Shark, Quickdraw and YOLO honestly

These are real GitHub profile achievements. They unlock by doing normal workflow, nothing hacky.

| Badge | Rule | How this project earns it |
|-------|------|---------------------------|
| **Pull Shark** | Have pull requests you opened get **merged** (bronze at 2, more tiers at 16, 128, 1024) | Every roadmap step is its own PR, so you get 13+ merged PRs |
| **Quickdraw** | **Close** an issue or PR within **5 minutes** of opening it | Open a small issue (or a throwaway PR) and close it right away |
| **YOLO** | **Merge** a PR **without a code review** | You are the only contributor; merge your own PR with no approval required |

## Requirements that trip people up

- The repo should be **public** (or enable "Include private contributions" in your profile settings, but badges are most reliable on public repos).
- Do **not** enable branch protection that requires reviews on `main`, or YOLO becomes impossible.
- The PR must be merged **into the default branch** of the repo.
- Badges can take a few minutes to hours to appear; check your profile page.
- Display them: Profile -> Settings -> Public profile -> Achievements.
